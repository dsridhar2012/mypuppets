Change Detector

A friendly workspace watcher that notices file changes and turns them into clear, colorful desktop bubbles.

What it does

The watcher checks this project about once a second. When it sees a real change, a large balloon rises from the bottom of the screen, pauses near the top for at least five seconds, then bursts into colorful glitter. The file name and a short change preview appear right on the balloon.

Green · AddedNew files, folders, or text lines.
Red · RemovedDeleted files, folders, or text lines. An edit that removes lines is red, too.
Blue · ChangedOther edits, such as a permissions change.

Unchanged files stay quiet. Git internals and Python's generated __pycache__ folder are ignored.

Start or stop watching

  1. Open a terminal in the project folder.
  2. Start the watcher with python3 scripts/change_detector.py.
  3. To stop it, focus that terminal and press Ctrl+C.
Good to know: The change_detector Copilot agent explains and manages this watcher, but the watcher is a separate process. It must be running to show popups.

Keeping this guide up to date

Whenever the agent's behavior, notification design, settings, or start/stop steps change, update this guide at the same time. That way, the instructions and the actual experience stay in step.
